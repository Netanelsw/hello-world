# 02 — Test 1: Short-tail + Dual Monetization

**Pass bar:** Margin per page ≥ old blended margin; dual monetization layer adds ≥15% revenue on the same traffic.
**Decide by:** Week 4.
**Owners:** Shaked (traffic/PPC) + Netanel.
**Dev needed:** None — reuses existing infrastructure.

---

## What this test proves

That the business has a viable core after cutting the long tail — and that layering partnerships/Creator Connections on top of that core generates meaningful incremental revenue without requiring new infrastructure.

This is the stabilization play. It doesn't make you whole, but it proves you have something to build on before the other three tracks need to carry weight.

---

## 2.1 The setup

**Step 1 — Define "short-tail."**
Use the threshold audit from 01 to identify which campaigns still have measurable conversion. These are short-tail. Everything else pauses.

- Short-tail = products/categories where monthly click volume clears Amazon's new reporting thresholds
- Target: top 20–50 landing pages / product clusters by measurable post-March conversion volume

- [ ] Pull top pages by conversion volume (post-March 9/18 data only — pre-March is contaminated) `[Hex]`
- [ ] Confirm which of those have paid traffic and check paid/boosted-ad disqualification risk `[Shaked]`
- [ ] Set the cut line: everything below it pauses immediately

**Step 2 — Concentrate spend.**
Reallocate freed long-tail budget to surviving short-tail. This tests whether concentrated measurable inventory outperforms dispersed dark inventory.

- [ ] Reallocate budget week 1
- [ ] Set daily spend caps per campaign with measurable ROAS floor

**Step 3 — Layer dual monetization.**
On the same surviving pages:
- **Creator Connections (US):** Enroll eligible pages. Additive commission on top of Associates, same traffic.
- **Partnership placement:** Approach brand partners for fixed or CPC placement on high-traffic pages. Separate tracking path — no cross-contamination with Associates tags.

- [ ] Identify pages eligible for Creator Connections `[Mark G]`
- [ ] Identify top 5–10 pages for partnership outreach `[Netanel + Mark G]`
- [ ] Confirm brand-deal tracking is a separate path, never mixed with Associates tags

---

## 2.3 Pass / fail

**Pass:** Margin per surviving page ≥ old blended at portfolio level, and dual monetization adds ≥15% incremental.
→ Short-tail core is viable. Scale it as the stable base while Tests 2–4 run.

**Fail:** Concentrated short-tail still doesn't hold margin, or short-tail volume is too thin to generate meaningful revenue.
→ Amazon Associates is more structurally broken than modeled. The core is gone, not just the tail. Urgency on Tests 2–4 increases sharply — they become the primary plan, not the parallel bet.
