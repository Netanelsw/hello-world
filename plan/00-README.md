Scaffold for the Kibeeri restructure & recovery plan. Read `../CLAUDE.md` first for
full context, constraints, and people.

the operating model and migration map define the response; diversification, org, and
financials cost it; the risk register and timeline gate execution.

## Rules for filling these in
- Pull real numbers from Hex, partners.kibeeri.com, or Gmail threads. Never invent.
- Flag every assumption inline. Mark unverified figures `[VERIFY]`.
- Projections are directional, not commitments — caveat on every forward-looking table.
- Keep Associates vs. brand-monetization (CPC/Fixed/ACC/Attribution) strictly separate.
- Model the floor, not the upside.
