# Recovery Plan — Working Docs

**Frame:** Run all four tracks as time-boxed parallel tests. Define the pass-bar before you start. Kill losers fast. Hire behind the 1–2 that clear the bar.

**Funding move — Week 1, no test needed:** Cut unmeasurable long-tail ad spend immediately. Amazon killed ASIN/user-level reporting (US Mar 9, EU Mar 18 2026). Any long-tail campaign you can't measure is now a blind spend. Free that budget. It bankrolls the four tests below.

---

## The four tests (run in parallel from Week 1)

| # | Test | Pass bar | Key owners | Decide by |
|---|------|----------|------------|-----------|
| 1 | Short-tail + dual monetization | Margin/page ≥ old blended; dual layer adds ≥15% rev on same traffic | Shaked + Netanel | Wk 4 |
| 2 | Amazon Attribution (US brands) | Brand payout ≥ 1.5× Associates on same traffic; measurement granularity restored | Daniel + Mark G | Wk 6 |
| 3 | MeLi — first marketplace | Positive contribution margin + usable ASIN-level reporting | Adi (commercial) + Aviran (tech) | Wk 6 |
| 4 | Brand-direct / agency | One brand's full funnel at gross margin ≥ affiliate contribution margin | Netanel (test) → dedicated hire (scale) | Wk 8 |

Tests 1–4 run in parallel. Tests 1 and 4 need no dev. Tests 2 and 3 use different dev resources (Daniel vs. Aviran) so no bottleneck.

---

## Kill signals (pre-committed before tests start)

- **Test 3 dies** if MeLi reporting is as blind as post-March Amazon. Don't rebuild the same broken engine on a smaller platform.
- **Test 4 dies** if deal #1 doesn't reach margin parity with current affiliate. Don't pitch an agency before unit economics are real.
- **Test 2 dies** if Attribution brand payout doesn't beat Associates by a meaningful margin after setup friction.

---

## Post-test: hire behind the winners

Dedicated hires don't start until a test clears its pass bar. Which track scales determines which role gets hired. Don't pre-hire speculatively across all four.
