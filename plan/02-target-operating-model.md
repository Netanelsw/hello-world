# 02 — Target Operating Model

**Goal:** Define what Discovery is *after* the transition. The four-axis flip made
concrete — page strategy, monetization mix, marketplace mix.

## 2.1 The flip, axis by axis
For each axis: where we are now → where we're going → what has to change to get there.

| Axis | Today | Target | What changes |
|------|-------|--------|--------------|
| Page strategy | Thin long-tail programmatic | Fewer high-intent editorial-grade experiences | |
| Monetization | Associates CPS | Dual: brand-direct CPC/Attribution/ACC + Associates | |
| Marketplace | Amazon-dependent | Multi-marketplace | |
| Asset ownership | Rented traffic (Google→Amazon) | Owned lists + social | |

## 2.2 Monetization mix (target state)
Keep tracks strictly separate — do not blend in the same row.

- **Associates** — where it survives, which GEOs, what it still earns
- **Brand-direct CPC** — primary replacement; rate = historical commissions ÷ clicks
- **Fixed fee** — predictability play, premium placement
- **ACC / Creator Connections** — US lane
- **Attribution** — standalone or brand-owned measurement, never mixed with Associates
