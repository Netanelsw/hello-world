Swiss K.Y. Association — Grant Audit Tool

How to use

  1. Select or drag your budget folder files: one master Excel (name contains “master” or “summary”), one Excel per project, and one scanned invoice PDF per project.
  2. Optionally type the period label you want to cross-check (e.g. 11-12-2025).
  3. Click Run Audit and wait — the full report appears below.
Tip: All processing happens in your browser. No files are uploaded to any server.
